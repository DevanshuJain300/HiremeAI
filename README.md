# HireMe AI

HireMe AI is an AI-powered Candidate Interview Assistant that allows users to interact with a candidate's resume through a conversational interface.

## Features

- AI-powered resume parsing
- Candidate profile extraction
- Resume-based AI chat
- HR Interview mode
- Technical Interview mode
- Project Interview mode
- Resume Interview mode
- AI-generated suggested questions
- Markdown-formatted responses
- Chat history
- Clear chat functionality
- Backend connection status
- Responsive dark UI

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Markdown

### Backend
- FastAPI
- Python
- Pydantic
- Groq API
- PyPDF
